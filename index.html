    ① 기존 이름으로 입장하면 이전에 등록한 곡이 즐겨찾기에 나타납니다.
    ② ‘노래 찾기’에서 검색 후 ☆를 누르면 저장됩니다. TJ와 금영의 제목·가수가 정확히 일치하는 결과만 한 카드에 묶습니다.
    ③ 곡 업데이트는 전날까지의 신곡을 저장합니다. 첫 실행은 최근 3개월, 이후에는 마지막 확인 월의 전달부터 재확인합니다. 전체 과거 곡은 온라인 검색으로 찾습니다.
    ④ ‘확인 기준일’은 조회 범위이며, 실제 최신 수록일·공급처 갱신 시점과 다를 수 있습니다. 금영의 월 단위 수록일은 원본 표기를 따릅니다.
    ⑤ 이름 입력은 기존 방식과 동일한 프로필 선택입니다. 같은 이름을 아는 사람은 같은 목록에 접근할 수 있습니다.
    ⑥ 검색은 비공식 API Manana를 사용합니다. 제공처·네트워크 장애 시 저장한 즐겨찾기는 계속 볼 수 있고, 검색은 저장된 신곡 안에서만 가능합니다.
